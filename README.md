# 🎬 Netflix Data Science & Recommendation System

## 📌 Project Overview

This project analyzes the Netflix Movies and TV Shows dataset and builds a content-based recommendation system.

The application allows users to select a Netflix movie or TV show and receive recommendations for similar titles.

## 🎯 Project Objectives

- Analyze Netflix content using Python
- Perform data cleaning and exploratory data analysis
- Use SQL for data analysis
- Build a content-based recommendation system
- Use TF-IDF and Cosine Similarity
- Create an interactive web application using Streamlit

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Scikit-learn
- Streamlit
- GitHub

## 🤖 Machine Learning

The recommendation system uses:

### TF-IDF

TF-IDF converts text information such as genres, descriptions, cast, and directors into numerical features.

### Cosine Similarity

Cosine similarity compares the similarity between Netflix titles.

The system then recommends the titles with the highest similarity scores.

## 📊 Dataset

The project uses the Netflix Movies and TV Shows dataset containing information such as:

- Title
- Type
- Director
- Cast
- Country
- Release Year
- Rating
- Genre
- Description

## 🌐 Streamlit Application

The Streamlit application allows users to:

1. Select a Netflix movie or TV show
2. View information about the selected title
3. Generate similar-title recommendations
